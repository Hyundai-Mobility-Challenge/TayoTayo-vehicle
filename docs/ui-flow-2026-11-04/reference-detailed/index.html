통학메이트 화면 이동도

실제 버튼과 화면 구조를 코드에서 확인해 그린 축약 와이어프레임입니다. 앱 화면 캡처나 새로 구현된 UI가 아닙니다.

학부모: 홈 카드의 상태 변화 · 차량: 하원 본문 교체와 상세 패널 이동 · 두 앱 연동: 조작부터 알림까지. 작은 화면에서는 원본 크기로 좌우 이동하거나 PNG를 열어 확대하세요.

학부모 화면 구조 · 상세 근거

P01 로그인/가입

별도 화면 이동 없이 join 상태에 따라 이름 입력과 버튼이 바뀝니다. 비로그인 폼에 개발용 서버 주소가 표시됩니다.

P02 → P03

초대 수락 성공 후 같은 홈에 어린이 카드가 생깁니다. 별도의 어린이 상세 Activity/페이지는 없습니다.

P03 카드

여러 아이가 있으면 카드가 세로로 나열됩니다. 대기·이동·도착·완료는 같은 TrackingCard의 상태입니다. 예시 ETA 5분은 측정값이 아닙니다.

추가 연결 / 최근 기록

홈에서 입력 영역과 최근 기록 영역을 펼칩니다. 최근 기록은 현재 코드상 최대 6개입니다.

설정 / 알림 진입

알림·설정은 AlertDialog입니다. 푸시 탭은 MainActivity를 열며 특정 아이 카드로 자동 이동하는 처리는 없습니다.

공유

Android 공유창은 OS 화면, 링크 수신 화면은 웹입니다. 링크는 읽기 범위만 주며 인계 권한이 아닙니다. 공유 웹에는 선택적으로 지도 보기가 남아 있습니다.

차량 화면 구조 · 상세 근거

기본 하원 화면

panel=flow 안에서 TeacherFlow가 단계에 따라 본문을 바꿉니다. 가로 화면은 좌측 정류장 목록, 작은 화면은 상단 간단 목록입니다.

기관 진입

하원 하단의 기관 · 배정 명단 버튼 또는 명단 · 상세 → 기관 연결 탭으로 접근합니다. 명단 준비가 성공하면 panel=flow로 돌아옵니다.

탑승 / 경로

탑승 기록을 반복하거나 탑승 마침을 누르면 순서 확인 본문으로 바뀝니다. 현재는 최소 한 명 탑승으로 진행할 수 있습니다. 전원 출결 확정 기능은 별도입니다.

출발 / D

이 순서로 · 운행 시작이 출발 액션입니다. D 관측은 순정 내비 전면 요청이며 앱이 기어를 바꾸지 않습니다. 하원 하단 Pleos 내비 지도 버튼도 있습니다.

하차 다음 단계

메인 하원의 하차 기록은 recordAlightingAndContinue를 호출합니다. 같은 지점 마지막 아이가 처리되면 다음 목적지로 자동 진행합니다. 별도 상세 조작 흐름은 버튼과 행동이 다를 수 있습니다.

예외 / 복귀 / 종료

보호자 미도착 예외는 현재 상세 조작 화면에 있습니다. 모든 하차 지점 방문 후 출발지 복귀·정차 확인 → 미하차 기록 확인 → 실내 확인·종료를 거칩니다.

정차와 근접 알림

일반 기록은 최신 속도 0/P/연결/UX 조건입니다. 근접 알림은 별도 조건과 현장 검증이 필요하며, 자동 도착·인계·하차를 의미하지 않습니다.

현재까지의 한계

실도로 주행, 차량 근접 때 OEM 팝업과 탭 복귀, 외부망 공개 운영은 미검증입니다. OS의 FCM 수신은 사용자의 읽음/인계 확인과 다릅니다.

제안 A · 보호자 홈

여러 아이가 늘어나면 카드 목록과 아이 상세 화면을 분리할지 검토합니다. 지금은 존재하지 않는 상세 화면이므로 현재 이동도에 넣지 않았습니다.

제안 B · 알림 진입

알림을 누르면 해당 아이 카드로 바로 이동하고 강조하도록 개선할 수 있습니다. 현재는 홈 진입까지입니다.

제안 C · 차량 예외 처리

보호자 미도착/동승 유지 버튼을 메인 인계 화면에서 바로 열도록 하면 상세 패널 왕복을 줄일 수 있습니다. 아직 적용하지 않았습니다.

제안 D · 일상/시험 분리

연결 완료 후의 기관 코드 입력, 모의 운행, 문 시험, 중복된 상세 조작 동선을 운영 화면에서 더 분리할 수 있습니다. 기존 기능 삭제 없이 설계 검토가 필요합니다.

제안 E · 시간의 의미

차량 순서 검토의 예시 계산 시간과 보호자에게 전달되는 실제 Pleos ETA를 더 명확히 구분하면 시연 설명이 쉬워집니다.

파일은 이 폴더만으로 열립니다. 외부 서버·지도·폰·에뮬레이터에 접속하지 않습니다. 앱 코드와 기기 상태는 변경하지 않았습니다.
