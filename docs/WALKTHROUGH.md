# 동승 선생님용 하원 체험

**0.1.5-poc**의 기본 화면에서 큰 버튼을 따라간다. 음성은 단계가 바뀔 때 자동으로 나오며, 놓쳤을 때만 **다시 듣기**를 누른다.

| 순서 | 선생님 조작 | 앱이 이어서 하는 일 |
|---|---|---|
| 탑승 | 어린이별 탑승 기록 → 운행 시작 | 방문 순서 계산·적용, 첫 지점 음성 안내 |
| 도착 | 도착·정차 확인 | 해당 어린이 표시, 인계 안내 |
| 인계·하차 | 인계 확인 → 하차 기록 | 다음 어린이 표시. 마지막 아이면 다음 지점·음성으로 자동 전환 |
| 복귀 | 출발지에서 복귀·정차 확인 | 실내 확인 안내 |
| 종료 | 실내를 직접 살핀 뒤 실내 확인 완료 · 운행 종료 | 완료 기록 저장 |

## 인계와 하차만 기록하기

![인계 확인](../evidence/operational-flow-0.1.4/guide-04-handover.png)

인계를 확인하면 같은 자리의 버튼이 **하차 기록**으로 바뀐다. 현재 지점의 마지막 아이를 기록하면 별도 다음 버튼 없이 다음 목적지가 나타난다.

![하차 기록](../evidence/operational-flow-0.1.4/guide-05-alight.png)

## 모의 체험과 실제 연결의 차이

모의에서도 같은 절차를 쓴다. 지점 이동은 실제로 일어나지 않으므로 도착을 가정하고 **도착·정차 확인**을 누른다. 차량 연결에서도 도착은 선생님이 확인한다. 현재 앱은 신뢰할 수 있는 위치 기반 도착 자동 판정을 구현하지 않았다.

문 시험과 진단은 **명단 · 상세 → 테스트 도구** 안에 있다. 정상 하원에서는 들어갈 필요가 없다. 미하차를 남긴 예외 진행이나 기록 정정이 필요한 경우에만 상세 명단에서 사유를 남긴다. 다음 지점 표시는 실제 차량 출발의 승인이나 문·주변 안전 확인이 아니다.

앱을 벗어나면 안내를 중지한다. 같은 화면으로 돌아올 때 반복하지 않으며 필요하면 **다시 듣기**를 누른다. 초기화·발화 실패는 표시하고 수동 재시도할 수 있다. 음성 안내 실패가 인계·하차 사실을 대신 만들지는 않는다.

기존 완료 기록을 보관하고 새로 체험하려면 **기록 보관 후 새 모의 운행**을 누른다. [검증 범위와 결과](VERIFICATION.md)

## 팀원과 상세 화면 확인하기

**명단 · 상세**를 열면 네 명의 이름·하차 지점·기록 상태가 보인다. 기록 정정은 해당 줄에서, 방문 순서 조작은 아래 버튼에서 연다. 하원을 계속하려면 오른쪽 위 **하원으로**를 누른다.

![간결한 명단](../evidence/details-0.1.5/details-roster.png)

**테스트 도구**에서 필요한 시험 하나를 선택한다. 진단·센서·연결 로그는 **펼치기**를 눌러 확인한다.

![테스트 도구](../evidence/details-0.1.5/details-tools.png)

팀원에게는 정본 프로젝트의 `app/build/outputs/apk/debug/app-debug.apk`를 전달해 Pleos 에뮬레이터에서 설치·체험할 수 있다. 이번 검증은 Pleos Connect v2.1.0의 가상 명단 기준이며 실제 차량 배포 검증은 아니다.


## 0.1.6 팀원 체험 메뉴

상세 → 테스트 도구 → 체험 시작·공유를 펼친다. 기본 운행 화면의 자동 안내와 인계·하차 흐름은 그대로다.
- 음악 정지는 재생 위치를 처음으로 되돌린다. 일시정지는 현재 위치를 유지한다. 음원은 시험 멜로디다.
- 처음부터 / 하차 지점부터 / 종료 점검부터를 고른 뒤 보관하고 시작을 누른다. 현재 운행을 별도 파일에 보관하고 읽어 확인한 뒤 새 가상 운행을 저장한다. 취소하면 유지된다. 차량 연결 모드에서는 이 기능을 제공하지 않는다.
- 중간 단계는 가상 사전 설정이다. 실제 탑승·인계 기록을 생성하지 않으며 종료 점검도 직접 확인해야 한다.
- 보관 기록은 운행 식별자·단계·기록 수·탑승 인원 요약을 보여준다. 과거 기록 편집이나 운행 재개는 제공하지 않는다.
- 결과 공유는 Android 공유 창을 연다. 앱 버전·현재 단계·가상 기록·진단이 포함된다. 공유 대상과 전송은 사용자가 선택한다. 에뮬레이터에 수신 앱이 없으면 공유할 앱을 설치하거나 내부 진단 파일을 사용한다.
