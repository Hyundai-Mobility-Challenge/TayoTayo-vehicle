# 화면 명세

캔버스 파일명은 `canvas/` 사본과 같다. 크기는 캔버스 기준 CSS px이며 dp 환산은 [TOKENS.md](TOKENS.md)의 '단위' 참고.

## 공통 구성

| 영역 | 가로 전체화면 (1280×920) | 세로 분할 (620×920) |
|---|---|---|
| 헤더 | 높이 72. 로고, `통학메이트`, 운행 이름(`하원 · 2호차 · 15:30 출발`), 오른쪽 상태 칩(정차 중·곧 도착·예외 처리 중)과 인원·정류장 칩 | 높이 64. 칩 1–2개 |
| 왼쪽 패널 | 폭 360. 기본은 정류장 타임라인(출발 · 정류장 1–4 · 복귀/도착). 화면에 따라 운행 선택, 달라진 점, 바꾼 결과, 재생목록으로 바뀜 | 없음. 타임라인은 본문 안 '이후 정류장' 줄로 접음 |
| 본문 | 현재 단계 카드. 노란 주요 버튼은 화면당 1개, 맨 아래 | 같은 내용을 한 열로 |
| 동요 바 | 높이 88. 상태 라벨, 곡·목록 이름, 안내 다시 듣기, 재생/일시정지, 동요 고르기 | 높이 76. 아이콘 버튼 위주 |

타임라인 행 상태: 완료(블루 원 + 흰 체크), 현재(흰 카드 + 호박색 테두리, 보조 문구 호박색), 예정(회색 테두리 원). 시스템 UI(상태바·공조 패널)가 앱 창 위를 잠시 덮을 수 있어 핵심 버튼을 가장자리에 붙이지 않는다.

## 준비

### L1 오늘의 통학 · `L01-Today` / 분할 `P01-Today`
- 목적: 출발 전 결석·하차 지점 변경·인계자 변경을 한 화면에서 확인
- 왼쪽: 오늘 운행 카드(등원 완료 / 하원 다음 운행). 변경이 어디서 오는지는 `[확인 필요]`
- 본문: 변경 카드마다 종류 칩, 아이 이름, 내용, 출처·시각, `확인` 버튼 → `확인함`. 탑승 예정 명단 칩(결석 아이는 취소선)
- 주요 버튼: 모든 변경을 확인해야 `경로 확인하기`가 열림. 닫혀 있을 때 문구 `변경 2건을 더 확인하면 경로를 볼 수 있어요`

### L2 경로 확인 · `L02-Route`
- 왼쪽: **평소와 달라진 점**(빠짐·추가·인계자 칩), **보호자 도착 알림** 스위치(보내는 방식 `[확인 필요]`), `순서를 정하는 기준 보기` 버튼
- 기준 목록(승인 정류장만 · 인도 쪽 하차 진입 · 횡단 최소 · 약속 시간 · 결석 제외)은 처음 쓸 때 한 번, 이후에는 버튼으로만 열고, 순서를 바꿔 기준에 어긋날 때 그 자리에서 경고로 보여준다
- 본문: 방문 순서 띠(출발 → 1–4 → 복귀, 정류장별 도착 시각·인원), **정류장 메모**(진입 방향·정차 위치·약속 시간)
- 버튼: `순서 바꾸기`(보조) · `이 순서로 · 기관 승차 시작`(하원) / `이 순서로 · 운행 시작`(등원)
- 직접 바꾼 순서면 제목 옆 `직접 바꾼 순서` 칩

### L9 순서 바꾸기 · `L09-Reorder`
- 진입: 경로 확인의 `순서 바꾸기`. 운행 중에는 차가 멈췄을 때만
- 본문: 출발·복귀 행은 잠금. 정류장 행마다 번호, 이름, 아이들, 새 도착 시각(바뀌면 원래 시각 취소선), 위·아래 버튼(64×52, 끝 행은 비활성). 마지막으로 옮긴 행은 노란 번호 + 호박색 테두리
- 경고(코랄): 약속 시간보다 일찍 도착, 진입 방향 때문에 길을 건너 내릴 수 있음, 등원 기관 도착 09:00 초과
- 왼쪽: 복귀(도착) 예정 시각 비교와 `+7분` 같은 차이 칩, 총 소요 비교, 확인할 점 개수, 바꾸는 이유(보호자 요청·도로 상황·기타, 선택)
- 버튼: `취소` · `제안 순서로 되돌리기` · `이 순서로 정하기`
- 끌어서 옮기기 대신 버튼을 쓴 이유: 차 안 흔들림에서 정확도. 계산 규칙은 [FLOW.md](FLOW.md#순서-바꾸기-계산)

### L13 기관 승차 (하원 출발 전) · `L13-Boarding`
- 본문: 아이 7명 4열 격자. 누르면 `탑승 · 벨트 확인`(블루)으로 바뀜
- `타지 않음으로 기록`: 보호자가 기관에서 바로 데려가는 등 결석이 아닌 미탑승
- 주요 버튼: 모두 확인해야 `출발 · 첫 정류장 안내`. 그 전에는 `2명 더 확인하면 출발할 수 있어요`

## 이동

### L3 이동 중 · `L03-Moving` / 분할 `P02-Moving`
- 보기 전용. 다음 정류장 이름(48), 남은 시간(104), 거리·도착 예정, 하차 방향 칩, 내릴(탈) 친구 카드와 오늘 변경 칩
- `순정 내비로 안내 중` 표시. 분할에서는 `옆 화면 내비로 안내 중`
- 하단 고정 안내: `주행 중에는 보기만 해요. 인계와 기록은 차가 멈춘 뒤에 할 수 있어요.`
- 동요 바: 재생 중, 일시정지·다음 곡만

### L4 하차 준비 · `L04-Approach`
- 정류장 접근(시안은 300m) 시 자동 전환. 상태 칩 `곧 도착`
- 안내 음성 배너: `곧 푸른마을 3단지 정문이에요. 하린, 도윤 친구 내릴 준비해요.` 음악은 설정값(기본 30%)으로 줄임
- `정차하면 할 일` 3단계. 주요 버튼은 차가 멈추기 전까지 비활성: `차가 멈추면 인계를 시작할 수 있어요`
- 접근 감지 방법은 미정 — [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md#먼저-확인할-것)

## 정차·인계

### L5 정차·인계 (하원) · `L05-Handover` / 분할 `P03-Handover`
- 상단 확인 두 개: `차량 정차 확인됨`(차량 신호) · `문 쪽 오토바이·자전거 없음 · 직접 확인`(선생님이 누름). 직접 확인 전에는 아이 행동 버튼이 잠김
- 아이 행마다: 이름, 오늘 변경 칩, 인계 예정자, `보호자가 안 보여요`(코랄 외곽선), `인계 확인` → 같은 자리에서 `하차 기록`
- 첫 번째로 처리할 아이만 노란 버튼, 나머지는 호박색 외곽선 버튼
- 모두 기록하면 `모두 기록했어요 · 다음 정류장 안내로 넘어가요` 후 자동 전환

### L8 정류장 승차 (등원) · `L08-MorningPickup`
- L5와 같은 틀. 행동은 `인계받기` → `승차·벨트 확인`, 예외 버튼은 `아이가 안 나왔어요`
- 하단 안내: 모두 타면 다음 정류장, 기관에 도착하면 기관 선생님께 한 번에 인계

### L6 보호자 미도착 (예외) · `L06-Exception`
- 상태 칩 `예외 처리 중`, 타임라인 현재 행도 코랄
- 선택지: `아빠에게 전화`(등록된 번호) · `3분 더 기다리기`(다른 아이 기록은 계속) · `동승 유지 · 기관에서 인계`(등원은 `오늘은 타지 않음으로 기록`)
- `고른 내용과 시간이 운행 기록에 남아요.` 동승 유지한 아이는 종료 점검에서 정리해야 종료 가능

### L11 아이 상세 · 인계 가능자 · `L11-ChildDetail`
- 진입: 인계 화면에서 아이 이름을 눌러 엶(제안)
- 왼쪽: 아이 이름, 반, 하차 지점, 지금 상태, 오늘 변경, 기관 메모
- 본문: 기관이 등록한 인계 가능 보호자 목록(사진 자리, 관계, 이름, 전화). 오늘 인계 예정자는 호박색 테두리
- `목록에 없는 사람이 왔어요`: 인계하지 않고 등록된 보호자에게 전화로 확인
- 사진·연락처 출처와 보관은 `[확인 필요]`

## 종료

### L7 운행 종료 점검 · `L07-EndCheck` / 분할 `P04-EndCheck`
- 기록 대조 타일 4개: 승차 · 하차·인계 · 미완료 인계 · 결석
- 동승 유지한 아이가 있으면 코랄 행 + `기관 선생님께 인계함`
- 직접 확인 3항목(맨 뒷좌석까지 걸어가 확인 · 좌석 아래와 사이 · 두고 내린 물건). 모두 체크하고 미완료 인계가 0이어야 `직접 확인 완료 · 운행 종료`
- 확장 슬롯: 좌석 착석·벨트 신호(지원 차량), 보조 정보이며 직접 확인을 대신하지 않음

### 기관 인계 (등원 도착) · 프로토타입에만 있음
- 차 안 아이 칩 목록, `기관 선생님께 n명 인계 완료` → 종료 점검

### L12 운행 기록 · `L12-TripLog`
- 왼쪽 요약: 출발→복귀 시각, 소요, 승차·하차·예외·결석, 직접 확인 3/3
- 본문: 시간순 기록(시각 · 정류장 · 아이 → 인계자, 변경·예외 칩). 선생님이 남긴 기록만 보여주고 센서 정보를 기록으로 바꾸지 않음
- 버튼: `기관에 공유`(방식 `[확인 필요]`) · `오늘의 통학으로`

## 동요

### L10 동요 고르기 · `L10-Music` / 분할 `P05-Music`
- 진입: 동요 바의 `동요 고르기`. 운행 전·정차 중에만. 주행 중에는 재생·일시정지만
- 왼쪽: 재생목록. 맨 위 `이번 주 노래`(운행마다 처음에 한 번, 일주일 반복 학습), 교통안전, 숫자·한글 놀이(등원 기본), 영어 동요, 계절 노래, 잔잔한 노래(하원 기본). 곡명은 `[곡명]` 자리표시, 음원 권리 확인 전
- 본문: 곡 목록과 미리 듣기, `이 목록으로 정하기`
- 자동 동작: 운행을 시작하면 재생(스위치) · 정류장이 가까워지면 음량(끄기/30%/50%) · 정차·인계 중 일시정지(항상 켜짐, 잠금) · 출발하면 이어서 재생(스위치) · 이번 주 노래를 먼저(스위치)
