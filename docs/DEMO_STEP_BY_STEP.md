# 현재 기본 시연 조작 순서

2026-11-04: **배정 명단으로 운행 준비**는 기본으로 Pleos 실제 연동 운행을 만든다. 일반 기관 화면에는 모드 선택 버튼이 없다. 초대 연결과 이미 허용한 권한은 그대로 사용한다.

1. 회사 PC의 차량 제어 페이지 http://127.0.0.1:8088/ 를 열어 DDS ONLINE인지 확인한다. 기어 P, 속도 0으로 둔다. 주차브레이크는 일반 운행 조건이 아니다.
2. 차량 앱에서 **기관 · 배정 명단 → 배정 명단으로 운행 준비**를 누른다. 자동으로 Pleos에 연결되고 탑승 화면이 열린다. 이미 진행 중인 운행이면 그 운행을 정상 마친 뒤 새 명단을 준비한다.
3. 표시되는 어린이마다 **탑승 기록**을 누른다.
4. 필요하면 **순서 바꾸기 → 이 순서로 정하기**, 이어 **이 순서로 · 운행 시작**을 누른다.
5. 위치/내비 시간 전송과 보호자 출발 알림이 자동으로 시작된다. 별도 위치 전송 또는 Pleos 모드 선택을 하지 않는다. 최초 권한이 없는 기기는 차량의 권한 안내를 한 번 허용한다.
6. 제어 페이지에서 **D**를 누른다. Pleos 내비 화면으로 전환되고 전송은 계속된다. 경로 요청 자체가 먼저 내비를 열 수도 있다.
7. 삼성폰의 **오늘의 하원**에서 민수의 예상 시간과 정류장 진행을 확인한다. 다른 어린이는 익명 정류장으로 표시된다. 앱은 약 5초 간격으로 갱신한다.
8. 기록할 때는 제어 페이지에서 **P / 속도 0**으로 정차한 뒤 차량의 통학메이트 아이콘으로 돌아온다. 가상 명단 시험에서는 도착을 가정하여 **도착·정차 확인 → 인계 확인 → 하차 기록**을 진행한다. 실제 운행에서는 현장을 확인해야 한다.
9. 민수 지점에서 **도착·정차 확인**을 누르면 폰에 도착 화면과 알림이 나온다. **인계 확인 → 하차 기록** 후 하차 완료와 공유 종료가 반영된다.
10. 모두 마치면 **복귀·정차 확인 → 실내 확인 완료 · 운행 종료**를 누른다.

가까운 실제 위치와 현재 경유지의 내비 거리, 최신 정차 상태가 함께 확인되면 차량 도착 알림을 누르며 돌아오는 기능도 구현되어 있다. 실제 근접 팝업 표시는 아직 검증하지 못했으므로 기본 시연은 앱 아이콘으로 돌아온다.

Pleos가 보내는 시간은 그대로 표시한다. 지난 시험의 에뮬레이터 위치는 판교, 가상 하차 지점은 서울시청 주변이라 민수 약 60분이었다. 제어 페이지의 D만 누른다고 GPS가 목적지로 이동하는 것은 아니다.

개발용 합성 이동은 준비 단계에서만 **명단·상세 → 테스트 도구 → 연결 방식 → 모의 체험**으로 명시적으로 선택할 수 있다. 정상 운행에는 필요하지 않다. 이 시험 모드는 실제 Pleos 시간이 아니며, 앱을 전면에 두어야 이동이 이어진다. **기록 보관 후 새 모의 운행**은 기관과 연결되지 않은 로컬 명단이므로 휴대폰 연결 시연의 시작 버튼으로 사용하지 않는다.
